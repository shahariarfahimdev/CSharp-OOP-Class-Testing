\# C# OOP Class Testing



A collection of five C# console applications demonstrating

object-oriented programming and software design principles.



\## Applications



\- EmployeeClassTest

\- EmployeeUserAccountClassTest

\- CustomerClassTest

\- CustomerUserAccountClassTest

\- CreditCardClassTest

\- Object-Oriented Programming (OOP)

\- Encapsulation

\- Constructors and Destructors

\- Static and Instance Properties

\- Factory Methods

\- GUID Generation

\- Authentication

\- Data Access Layer

\- Stub Methods

\- Functional Testing

\- Visual Studio 2026
